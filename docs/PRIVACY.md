# 隐私与安全

- 源码、发布包和文档不包含真实 API Key、用户照片仓库、人工评分任务或账户用量账本。
- macOS Key 保存在钥匙串，不回填到 JS。模型和地图请求均由使用者主动触发。
- 本机照片、预览、缩略图及 JSON 保存于用户 Application Support/Glimpse；应用移动或更新不会以源码仓库代替该目录。
- 模型只收到必要选区裁剪、mask 与描述。轮廓增强还提供编号候选边缘参考。请求不附带 GPS、EXIF 和整个日志。
- 模型返回受限路径数据，本地验证后构造 SVG；不注入任意 HTML/SVG。
- Token 上限为本机累计输入与输出 300 万，包括图片、思考与重试；取消和超时保持保守预留。此账本不代表其他设备的共享账户用量。
- 网页使用 IndexedDB 保存访问者自己的数据。网页设置中的 Key 只存本次内存，不能开启原生 Kimi 接口；不会从 macOS 钥匙串读取 Key。
- 相机只在主动拍照时开启；定位只在主动使用当前位置时申请，位置允许缺失。

提交问题时请勿附带凭据、完整照片仓库、个人定位或原始评分任务。测试原生桥接应使用隔离 GLIMPSE_QA_DIR；不要以正常数据目录自动跑有写入的检查。
