# 验收事实与当前限制

三个版本均有 TypeScript / Vite 构建和既有 31 项核心测试的历史通过记录。GitHub 导入会再次运行构建和核心测试，具体结果保存为发布整理证据。

v0.5.0 历史工程记录覆盖首页／开屏、导入取消、摄像头夹具、精细 mask、日志、质量入口与封包。v0.5.1 追加 20 项浏览器笔迹／入口检查、8 项横竖照片几何检查、9 项 WKWebView 笔迹检查、12 项离线 Hero 检查和 17 项静态站生产包检查。这些均是工程验证，不是 Kimi 语义质量评分。

原版真人 A3 为 10 张固定照片 × 2 个联想：结构 20/20、可用 5/20、端到端 P90 37.115 秒。阈值仍为结构至少 19/20、可用至少 16/20、P90 不超过 25 秒；质量和延迟未通过。轮廓增强没有完成新的真人评分，不承诺已提高可用率。

摄像头和地图的自动夹具不能替代真实设备／真实地点实测。Apple Silicon 二进制为交叉编译，不冒充 Apple Silicon 真机验收。浏览器 IndexedDB 不能与 macOS 文件仓库同步。

本仓库只有汇总事实，不上传固定任务的私人照片、原始评分 JSON 或真实用量账本。截图中预置显影的路径不会随描述变化；上传照片的网页显影为通用实验曲线。
