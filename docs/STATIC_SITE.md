## 与 macOS 版本的差别

显影使用原工程已有的 MockRevealProvider：示例为预置狐狸轮廓，上传照片为通用实验线稿，页面会说明这是演示，尚未真实理解照片和描述。

Kimi Code 实时识别、本地原生轮廓提取、macOS 钥匙串和 MapKit 系统地图依赖原生应用桥接，在 STATIC_SITE 中不可运行。设置页保留配置入口，但网页保存的 Key 仅在本次页面内存中存在，不能开启实时识别；地图页可回看位置列表。静态网站不能继承本机的 20 项评分记录。

保持 v0.5.1 的视觉、字体、页面关系、normalized 坐标和粉笔笔迹，网站图标使用用户新提供的图片。
